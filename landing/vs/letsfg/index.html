viajante vs LetsFG

Free, local flight search for AI agents. viajante runs on your machine and hands you the links. LetsFG runs on their servers and can book.

Last checked 21 October 2026. Sources are linked below.

  • Free, MIT license
  • No account or API key
  • Runs on your machine

When LetsFG is the better choice

Choose LetsFG when you want the tool to book. It books flights and hotels after you approve the booking by email. That is the job viajante does not do.

viajante searches hotels and returns the stay, the total, and the link. It does not complete the reservation. If the point of the session is a booked hotel, or a ticket bought for you, LetsFG is the better fit.

What viajante can search

These are in the current code. Each one has the limit named here.

Hidden-city search

Opt-in, and it uses Skiplagged, not Google. Quotes are USD. The rows stay separate from Google results. viajante still does not book. Confirm the fare on the row’s booking link when the card includes one.

Nearby dates, ±N days

On a one-way or round trip, the cheapest owned fare for each day from N days before the date you asked through N days after. A round trip shifts outbound and return together and keeps the trip length. It is off unless you ask. An unpriced day is not “no flights”.

Google price level and typical range

A flight search can include Google’s own label for the lowest price against the typical range on that page: low, typical, or high, plus the range. It is Google’s label, not a forecast, and it is absent when the page does not provide it.

Explore

Destinations from an origin you name. It needs the optional browser extra and Chromium, and it reads Google’s public Explore page. A destination that comes back without a price is unfinished, not proof that nothing flies there.

Emissions filter

One-way public flight search can ask the page for less-emissions flights. Round trips, multi-city trips, and browser detail refuse it, because those paths cannot show that the filter was applied.

Departure and arrival time windows

You can bound departure and arrival clocks. One-way public search sends those bounds to the page. Other trip types apply them to the rows that came back. An unknown clock does not count as a match.

Bag-aware pricing

On the public flight search, you can ask Google Flights to price one carry-on for the party. A separate ranking allowance can account for a bag in the quote currency. That allowance is not a bag fee. Checked-bag counts are refused, because no path can verify them.

Airline alliance filter

The public flight search can include oneworld, SkyTeam, or Star Alliance. Excluding an alliance is refused: the page cannot prove the exclusion.

Points and miles

Local award math on offers you supply: cents per point, and transfer paths. It does not search live award seats, and it does not book the award.

Clients

Claude, Cursor, and Hermes Agent, as a local MCP server, and as a Python package (pip install viajante).

Official Hermes Agent plugin

In Hermes Agent, the catalog install is:

hermes plugins install viajante

Or add the local MCP server directly:

hermes mcp add viajante --connect-timeout 300 --command npx --args -y @viajante/mcp

Setup for the other clients is on the viajante homepage.

What their docs do not describe

Checked 21 October 2026 in docs/mcp.md, docs/api-search.md, docs/agent-guide.md, and docs/cli-reference.md. Those pages do not describe hidden-city search, a ±N-day nearby search, an emissions filter, or an arrival-time window.

They do describe an outbound date window (date_from through date_to) and departure-time bounds (departure_time_from and departure_time_to). Absence from these docs is not proof the product can never do the thing.

Open requests

Issue #225 is open. It asks about frequent-flyer points, status, and booking with transferable points. On 12 October 2026 the maintainer wrote that frequent-flyer numbers can be saved and attached when they book, and that paying with points is not something they do yet.

Issue #233 is open. It asks for a filter by airline alliance (Star Alliance, SkyTeam, or oneworld). On 19 October 2026 the maintainer wrote that this is already supported in their system and that they will expose it in the MCP tools.

Questions

Is viajante free?

Yes. It is free, MIT licensed, and open source. It does not take payment, add a markup, or use affiliate links.

Does viajante need an account or an API key?

No. There is no account, login, OAuth, or API key. Install the command-line tool with pip. The MCP server runs on your machine, over stdio or on an optional HTTP endpoint bound to 127.0.0.1.

Does viajante book flights?

No. It never books and never takes payment. It links you to Google Flights or Booking so you book yourself.

Where do searches go?

From your machine to Google Flights, Google Hotels, and Booking. Skiplagged is contacted only if you opt in, for hidden-city search or Skiplagged hotels. Searches are not sent through a viajante server.

Does viajante cap how many searches you can run?

No. viajante does not set a search quota. If a source throttles, viajante pauses further requests to that source.

When is LetsFG the better choice?

When you want the tool to book the flight or the hotel. LetsFG books both after you approve the booking by email. viajante returns the rows and the links, and you book yourself.

Does viajante work in Claude, Cursor, and Hermes?

Yes. It runs as a local MCP server in Claude, Cursor, and Hermes Agent, and as a Python package. viajante is an official Hermes Agent plugin. In Hermes Agent, install it from the catalog with hermes plugins install viajante, or add the server with hermes mcp add viajante --connect-timeout 300 --command npx --args -y @viajante/mcp.
